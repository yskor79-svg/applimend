APPLIANCE PROBLEM GUIDE

Washer not draining.

Standing water and wet laundry are different observations. Note whether water is actually left in the drum or the load is simply wetter than usual.

Start with what you can observe.

These are general observations and simple user checks, not a diagnosis. Follow the instructions for your exact model and stop if a check is unclear or requires tools.

01 / CHECK

Read the cycle and display

Note the selected cycle, its stage and any exact code. Cycle and spin settings can affect how wet clothes are at the end.

02 / CHECK

Check the lid or door

For a top-loader, check that the lid is properly closed. Do not force a locked door or bypass a latch.

03 / CHECK

Use the correct model manual

Filter access and drain arrangements vary. Consult the manual before any maintenance; this guide does not ask you to open a filter or disconnect a hose full of water.

When to get help

If water remains or the cycle repeatedly stops, arrange an assessment rather than repeatedly restarting it. Leave a locked door, inaccessible drain or water-filled filter to someone qualified.

Details worth writing down

  • Whether water remains in the drum after the cycle
  • Selected cycle, spin setting and the stage at which it stops
  • Exact error code and whether the washer is stacked or built in

EXAMPLE DESCRIPTION

The washer stops before spinning and water remains in the drum. It happened on the last two loads. The display shows the same code each time.
